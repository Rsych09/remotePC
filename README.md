# RemotePC — Агент удаленного управления ПК через Telegram-бота

Фоновое десктопное приложение для Windows на языке **Rust**, позволяющее удаленно управлять компьютером через Telegram-бота с помощью интерактивного Inline-пульта (редактирование единого сообщения в реальном времени).

---

## ⚡ Особенности и архитектура

1. **Скрытая работа без консоли в релизе**:
   - В релизной сборке активируется `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`, предотвращая появление окна терминала.
2. **Многопоточность**:
   - **Главный поток**: нативный цикл событий Windows (`tao`) и иконка в системном трее (`tray-icon`).
   - **Фоновый поток**: полноценный асинхронный рантайм `tokio` (multi-thread) с циклом Long Polling для `teloxide`.
3. **Автозагрузка Windows (HKCU Run)**:
   - **Автоматически**: при первом и каждом последующем запуске с `autostart = true` программа сама прописывается в реестр автозапуска Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
   - **Управление прямо из Telegram**: кнопка `[🚀 Автозапуск: ✅ Вкл]` / `[🚀 Автозапуск: ❌ Выкл]` позволяет переключать автозагрузку одним тапом со смартфона.
   - **Управление из системного трея**: пункт `«Автозагрузка Windows (Вкл/Выкл)»` с нативным чекбоксом.
   - **В конфигурации**: параметр `autostart = true / false` в `config.toml`.
4. **Иконка в системном трее**:
   - Программная векторная генерация аккуратной изумрудно-зеленой круглой иконки 32x32 прямо в памяти (без внешних `.ico` файлов).
   - Меню трея:
     - «Отправить пульт в TG»
     - «Автозагрузка Windows (Вкл/Выкл)» (синхронизировано с реестром и `config.toml`)
     - «Выход»
5. **Безопасность**:
   - Строгая фильтрация по `allowed_user_id` во всех сообщениях и `CallbackQuery`. Запросы от посторонних ID полностью игнорируются.
   - Выключение и перезагрузка защищены интерактивным меню подтверждения: *«Точно выполнить? [✅ Да] [❌ Отмена]»*.
6. **Скриншоты без записи на диск**:
   - Захват экрана через `xcap` и кодирование в PNG в оперативной памяти через `std::io::Cursor` без записи на диск.
   - Отправка снимка в чат с кнопкой «🗑 Удалить».
7. **Оптимизация размера**:
   - Профиль релиза с `opt-level = "z"`, `lto = true`, `strip = true`, `panic = "abort"`.
   - Размер автономного `.exe` со всеми встроенными библиотеками — всего ~**2.26 МБ**!

## 🎮 Структура Inline-пульта

### Шапка сообщения (сводка системы):
```text
🟢 ПК запущен и на связи

📊 Состояние системы:
• Статус: Онлайн
• Загрузка CPU: 3.4%
• Занято RAM: 7.82 ГБ / 31.85 ГБ (25%)
• Таймер выключения: не активен (или: активен (через 29 мин 45 сек))
• Автозагрузка Windows: Включена (или: Отключена)
🕒 Время обновления: 10:11:00
```

### Сетка кнопок (2–3 кнопки в ряд + ряд автозапуска):
| Категория | Кнопки | Описание |
|---|---|---|
| **Питание** | `[🔌 Выключить]` `[💤 Сон]` | Выключение с подтверждением; переход в режим сна (`SetSuspendState`) |
| **Питание** | `[🔄 Перезагрузка]` `[🔒 Блокировка]` | Перезагрузка с подтверждением; мгновенная блокировка экрана (`LockWorkStation`) |
| **Таймер** | `[⏱ 30м]` `[⏱ 1ч]` `[⏱ 2ч]` | Запуск таймера выключения через системный вызов `shutdown /s /t SEC` |
| **Таймер / Статус** | `[❌ Сброс таймера]` `[🔄 Обновить статус]` | Отмена таймера через `shutdown /a`; ручное обновление метрик CPU/RAM |
| **Медиа / Звук** | `[🔉 -10%]` `[🔇 Mute]` `[🔊 +10%]` | Эмуляция клавиш `VK_VOLUME_DOWN`, `VK_VOLUME_MUTE`, `VK_VOLUME_UP` через `SendInput` |
| **Экран / Плеер**| `[⏯ Play/Pause]` `[📸 Скриншот]` | Пауза/воспроизведение медиа (`VK_MEDIA_PLAY_PAUSE`); захват экрана в ОЗУ |
| **Автозагрузка** | `[🚀 Автозапуск: ✅ Вкл]` | Быстрое включение/отключение автозапуска прямо из Telegram |

## 🛠 Конфигурация и запуск

Файл `config.toml`:
```toml
bot_token = "9188471878:AAEtsGuTKXbB3ZcRX005TeY5yu_SUwgQBZ8"
allowed_user_id = 1109865120
autostart = true
```

Готовый файл приложения: `target/release/remotePC.exe`.
При запуске программа автоматически прописывается в автозапуск Windows, сворачивается в трей и отправляет пульт в Telegram!
